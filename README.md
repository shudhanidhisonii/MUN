# 🌐 KIET MUN — Conference Website  

**KIET MUN** is a modern, React-based web application built to showcase and manage details for the upcoming **Model United Nations Conference 2025** at KIET.  
It provides essential information about committees, events, and allows participants to register seamlessly through a clean, interactive interface.

> “Where diplomacy meets design — connecting delegates through code.” ⚡

---

## 🚀 Features  

- 🏛️ **Conference Overview** – Displays event schedule, purpose, and committee details  
- 🧭 **Dynamic Committees Page** – Animated and responsive layout using **Framer Motion**  
- 📝 **User Registration** – Secure sign-up and form submission via **Supabase** integration  
- 🎨 **Modern UI Design** – Built with **React** and **DaisyUI** for a visually engaging experience  
- 📱 **Fully Responsive** – Optimized for desktop, tablet, and mobile devices  
- ⚡ **Fast & Interactive** – Powered by **Vite** for blazing development performance  

---

## 🛠️ Tech Stack  

### 🔹 Frontend
- **React.js** – Component-based, scalable architecture  
- **Vite** – Lightning-fast bundler and dev server  
- **TailwindCSS + DaisyUI** – Modern, elegant styling  
- **Framer Motion** – Smooth animations and transitions  

### 🔹 Backend / Database
- **Supabase** – Secure, real-time data storage and user registration handling
